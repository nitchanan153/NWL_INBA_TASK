NWL Task · บันทึกงานรายวัน

—

บันทึกอัตโนมัติ
ยังไม่มีข้อมูลในเบราว์เซอร์นี้ — พิมพ์ลงตารางได้เลย หรือนำเข้าไฟล์สำรอง .json จากเวอร์ชันเดิม

เลือก "การมาทำงาน" (ออฟฟิศ / WFA / ลา) ที่แถวบนสุดของแต่ละวัน และเลือก "สถานะงาน" (✓ ◐ ✗ ⊘) แยกในแต่ละ Task · งาน ◐ หรือ ✗ กด "↪ ทำต่อ" เพื่อยกไปวันทำงานถัดไป · ยกผิดวัน: ชี้ที่ช่องปลายทางแล้วกด "ย้ายวัน" หรือ "× ลบ" (หรือ "เลิกยก" ที่ช่องต้นทาง) · งานมอบหมายพิมพ์ในแถว Remark แล้วกด Enter, กด "→ ลง Task" เพื่อส่งเข้าช่อง Task · เมื่อ Task ที่มาจากงานมอบหมายขึ้น ✓ งานมอบหมายจะถูกติ๊กให้เอง · ดูทุกอย่างที่ยังเปิดอยู่ได้ที่ปุ่ม "งานค้าง" · ข้อมูลบันทึกในเบราว์เซอร์นี้อัตโนมัติ (ไม่ได้ส่งขึ้นเซิร์ฟเวอร์)

งานค้าง

วันหยุด (ไม่นับเป็นวันทำงาน)

ใส่วันหยุดนักขัตฤกษ์/วันหยุดบริษัท ตารางงานจะข้ามวันเหล่านี้ให้อัตโนมัติ (รวมถึงตอนยกงานไปวันถัดไป)

    ข้อมูลและการสำรอง

    ข้อมูลทั้งหมดเก็บใน LocalStorage ของเบราว์เซอร์นี้เท่านั้น ไม่ได้อยู่บนเซิร์ฟเวอร์ ถ้าล้างประวัติเบราว์เซอร์หรือเปิดจากเครื่องอื่น ข้อมูลจะไม่ตามไป ควรสำรองเป็นไฟล์ .json เป็นระยะ

    สำรองข้อมูล

    นำเข้าข้อมูลสำรอง

    เลือกไฟล์ .json ที่เคยสำรองไว้ ใช้ไฟล์จากเวอร์ชันก่อนได้ — ช่อง Task ที่เคยใส่ ลา / WFA จะถูกย้ายไปแถว "การมาทำงาน" ให้อัตโนมัติ · ข้อมูลปัจจุบันจะถูกแทนที่ทั้งหมด

    ล้างข้อมูล

    ลบบันทึกงานทั้งหมดในเบราว์เซอร์นี้ (วันหยุดยังอยู่) ควรสำรองก่อน
