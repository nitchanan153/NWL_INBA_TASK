# NWL Task · บันทึกงานรายวัน

เว็บแอปหน้าเดียว ไม่ต้อง build ไม่ต้องติดตั้งอะไรเพิ่ม เอาโฟลเดอร์นี้ขึ้น Vercel ได้เลย

## มีอะไรใหม่ในเวอร์ชันนี้

- **แยก "สถานะงาน" กับ "การมาทำงาน" ออกจากกัน**
  - สถานะงาน (✓ เสร็จแล้ว · ◐ กำลังทำ · ✗ ไม่เสร็จ · ⊘ ยกเลิก) เลือกแยกในแต่ละช่อง Task
  - การมาทำงาน (● ออฟฟิศ · ⌂ WFA · ○ ลา · – ไม่มีงาน) เลือกครั้งเดียวต่อวันที่แถวบนสุด และมีป้ายขึ้นที่หัววันที่ด้วย
  - แถบสรุปด้านบนนับจำนวนวัน ออฟฟิศ / WFA / ลา ของเดือนแยกให้
  - ข้อมูลเวอร์ชันเก่าที่เคยใช้ช่อง Task พิมพ์ว่า "WFA" หรือ "ลา" จะถูกย้ายไปแถวการมาทำงานให้อัตโนมัติ แล้วเลื่อน Task ที่เหลือขึ้นมาแทน (ลิงก์ "ทำต่อ" ยังชี้ถูกช่อง)
- พร้อมขึ้น Vercel: แยกไฟล์ ไม่ใช้ Tailwind CDN แล้ว ติดตั้งเป็นแอปบนมือถือ/คอมได้ และเปิดได้แม้ออฟไลน์

## โครงสร้างไฟล์

```
index.html              หน้าเว็บ
css/style.css           หน้าตาทั้งหมด
js/app.js               การทำงานทั้งหมด
sw.js                   service worker (ทำให้เปิดได้แม้ออฟไลน์)
manifest.webmanifest    ข้อมูลสำหรับติดตั้งเป็นแอป
icons/  favicon.ico     ไอคอน
vercel.json             ตั้งค่า Vercel (header ความปลอดภัย, กัน search engine เก็บหน้าเว็บ)
```

## Deploy ขึ้น Vercel

### วิธีที่ 1: ผ่าน GitHub (แนะนำ: แก้ไฟล์แล้ว push เว็บจะอัปเดตเอง)

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Private ก็ได้) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ชั้นบนสุดของ repo
2. เข้า [vercel.com](https://vercel.com) → **Add New… → Project** → เลือก **Import** repo นั้น
3. **Framework Preset: Other** ไม่ต้องใส่ Build Command หรือ Output Directory → กด **Deploy**
4. จะได้ลิงก์ประมาณ `https://ชื่อโปรเจกต์.vercel.app`

### วิธีที่ 2: Vercel CLI

```bash
npm i -g vercel
cd nwl-task-tracker
vercel          # ครั้งแรกจะให้ login และตั้งชื่อโปรเจกต์ → ได้ลิงก์ preview
vercel --prod   # ขึ้นเวอร์ชันจริง
```

## ย้ายข้อมูลมาเว็บใหม่ (ทำครั้งเดียว)

ข้อมูลเก็บใน LocalStorage ของเบราว์เซอร์และผูกกับโดเมน เว็บบน Vercel จึงเริ่มแบบตารางว่าง

1. เปิดไฟล์ `NWL_Task_Tracker.html` เดิม → ปุ่ม **ข้อมูล** → **ดาวน์โหลดไฟล์ .json**
2. เปิดเว็บใหม่บน Vercel → ปุ่ม **ข้อมูล** → **นำเข้าข้อมูลสำรอง** → เลือกไฟล์นั้น (หรือกดปุ่ม "นำเข้าไฟล์ .json" ที่แถบด้านบนตอนตารางยังว่าง)

ถ้าไม่มีไฟล์จากเวอร์ชันเดิม ใช้ `NWL_Task_data_from_xlsx.json` แทนได้ ไฟล์นี้คือข้อมูลจาก NWL_Task.xlsx (ก.ย.–พ.ย. 2569) ที่แปลงเป็นรูปแบบใหม่แล้ว

> ⚠️ อย่าเอาไฟล์ข้อมูล `.json` ขึ้น repo หรือขึ้นเว็บ เพราะลิงก์ `.vercel.app` ใครมีลิงก์ก็เปิดได้ ตัวเว็บในโฟลเดอร์นี้ไม่มีข้อมูลงานฝังอยู่ (`.gitignore` กันไฟล์ `.json` ไว้ให้แล้ว ยกเว้น `vercel.json`)

## ติดตั้งเป็นแอป

- **Chrome / Edge** (คอม, Android): กดปุ่ม **ติดตั้งแอป** มุมขวาบน หรือไอคอนติดตั้งในแถบที่อยู่
- **iPhone / iPad** (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
  แนะนำให้ทำ เพราะถ้าเปิดผ่าน Safari ตรง ๆ แล้วไม่ได้เข้าเว็บนี้ 7 วัน Safari อาจลบข้อมูลที่เก็บไว้ ส่วนแอปที่เพิ่มลงหน้าจอโฮมไม่โดนกฎนี้

## ข้อควรรู้

- ข้อมูลอยู่ในเบราว์เซอร์แต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง ควรกด **ข้อมูล → ดาวน์โหลดไฟล์ .json** สำรองเป็นระยะ
- อัปเดตเว็บ: แก้ไฟล์ → push ขึ้น GitHub (หรือ `vercel --prod`) → เปิดเว็บแล้วรีเฟรชก็ได้เวอร์ชันใหม่ (`sw.js` ดึงไฟล์ใหม่จากเซิร์ฟเวอร์ก่อนเสมอ)
- ลองบนเครื่องตัวเองก่อน deploy: `npx serve .` หรือ `python3 -m http.server 8000` แล้วเปิด http://localhost:8000
  (ดับเบิลคลิก `index.html` ก็ใช้งานได้ แต่จะไม่มีโหมดออฟไลน์และติดตั้งเป็นแอปไม่ได้)
